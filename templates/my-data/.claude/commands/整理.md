description: 把新导入的记录整理进理解层（knowledge/）
argument-hint: [来源或年份，例如 book 或 wechat_moments 2021]
---

请整理我的个人数据库。范围：$ARGUMENTS（为空则处理最近导入的记录）。

步骤：
1. 运行 `../personal-db/pdb stats` 了解数据量。
2. 读取对应的 `records/` 文件（按来源和年份分批，每批不要太多，读完一批再读下一批）。
3. 更新理解层：
   - `knowledge/me/profile.md`：我的身份、核心观点、方法论、表达风格、习惯
   - `knowledge/people/<名字>.md`：出现的重要人物（注意同一人的不同称呼，写进 aliases）
   - `knowledge/projects/<项目>.md`：项目目标、进展、关键决策
   - `knowledge/playbooks/<做法>.md`：我反复使用的做事方法（目标、工具、步骤、产物、坑）
   - `knowledge/timeline/<年份>.md`：这一年在做什么、在想什么、观点有什么变化
4. 遵守 CLAUDE.md 的规则：每条结论带出处 id；习惯需要 3 个不同日期的证据；不编造。
5. 运行 `../personal-db/pdb rebuild`。
6. 用 `git add -A && git commit` 提交，提交信息写明本次整理的范围。
7. 最后用几句话告诉我：新增/修改了哪些文件，有哪些结论不太确定、需要我确认。
